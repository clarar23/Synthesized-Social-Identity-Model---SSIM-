# Synthesized-Social-Identity-Model---SSIM-
This ABM represents the theoretical mechanisms of the Synthesizes Social Identity Theory as described in my thesis "SSIM: Modeling Identity Dynamics with Agent-Based Simulation". Code for the base model, 100-seed simulations, agent trajectory simulations and code for the experiments described in the thesis are provided.
The base model is the synthesizes theories mechanisms and can be found under SSIM.py. 
The 100-seed simulations are to be used to illustrate what patterns a complex system brings forth that interacts according to the SSIMs' mechanisms. 
The agent trajectory simulations are to be used to illustrate how individual agents behave according to the SSIMs' mechanisms. 
The code for the experiments are to be used to understand the experiments carried out in my thesis. 
The code allows for modification, so that more experiments and parameter changes can be carried out to understand which inferences the SSIM makes under different circumstances.
